# Behavioral corpus `fe-compatibility-scenarios`, schema version 1

Status: **frozen, revision 1, 21 November 2026.**
`fixtures/behavior/treasury-v0.json` is generated by `scripts/make-corpus.py`,
which `--check` reproduces byte for byte. It is loaded by `host/treasury.py`.

| Key | Content |
| --- | --- |
| `format`, `schema_version` | `fe-compatibility-scenarios`, JSON integer `1` |
| `interface`, `interface_sha256` | Treasury v0 revision 1, plus the SHA-256 of the vendored frozen ABI. A mismatch is rejected. |
| `actors` | Role → Anvil account: owner 0, delegate 1, recipient 2, outsider 3 |
| `deployment` | Treasury constructor arguments, the fixed deployment order of the shared harness contracts, and the reentrant recipient's arguments |
| `state` | 1–16 typed fields read after every action: getter words or account balances. Balances are net of the account's own gas fees. |
| `scenarios[]` | `id`, `description`, `aux` (the harness contracts deployed), `payee` (whose balance is observed), and 1–64 `steps` |

## A step

- `from` is the sender role. `to` is the target or a harness role.
- `call` and `args` give the call, or `calldata` gives raw bytes.
- `value` is the wei sent.
- `advance` adds seconds before the transaction. `t` is the expected
  timestamp offset from the scenario's first block; the loader checks it
  against the schedule.
- `scope` is `strict` or `rejection`.
- `covers` lists the exit-test behaviors the step exercises.
- `expect`, written from the spec, is one of:
  - `{"ok": {types, values}, "events": [{emitter, event, args}]}`: exact
    returndata and the exact ordered events;
  - `{"error": "Name(types)", "args": [...]}`: exact revert bytes;
  - `{"reject": true}`: a compiler-generated rejection, compared by status
    only.

## Values

A value is one of:

- a canonical decimal string;
- `"MAX"`;
- `{"role": name}`;
- `{"t": k}`, the scenario's first block timestamp plus `k`;
- `{"selector": "Error()"}`.

Expected bytes are encoded at run time by `cast`, independently of both
compilers. Every action is mined in its own block, one second after the last.
`advance` moves that schedule forward.
